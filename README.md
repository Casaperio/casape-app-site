# casape-app-site

Páginas públicas do app **Casapē Rio**, exigidas pela App Store e pelo Google Play:

- `https://app.casaperio.com/suporte/` — contato e horário de atendimento
- `https://app.casaperio.com/privacidade/` — política de privacidade (pt e en)

HTML e CSS estáticos, publicados pelo GitHub Pages a partir da `main`. Sem build,
sem framework, sem scripts ou fontes de terceiros. Este repositório é público:
não guarde nada além das páginas.
