# casape-app-site

Páginas públicas do app **Casapē Rio**, exigidas pela App Store e pelo Google Play:

- `https://casape-app-site.vercel.app/suporte/` — contato e horário de atendimento
- `https://casape-app-site.vercel.app/privacidade/` — política de privacidade (pt e en)
- `https://casape-app-site.vercel.app/termos/` — termos de uso (pt e en)

São estes os endereços cadastrados na App Store Connect e na Play Console. Mudar
um caminho aqui quebra o link nas lojas.

HTML e CSS estáticos, publicados pela **Vercel** (projeto
`casaperios-projects/casape-app-site`): cada commit na `main` vai para produção
sozinho, e cada PR ganha uma prévia. Sem build, sem framework, sem scripts ou
fontes de terceiros. Este repositório é público: não guarde nada além das
páginas.

O GitHub Pages foi desligado em 01/10/2026 — o site sai só pela Vercel.
